# اپلیکیشن اندروید مدیریت فروشگاه و سفارشات سبزینه (MoringaLab Store Manager)

اپلیکیشن اختصاصی موبایل برای مدیریت جامع سفارش‌ها، ثبت سفارش جدید، تعریف و ویرایش مشخصات محصولات، و مدیریت اطلاعات و سوابق مشتریان متصل به بک‌اند فروشگاه سبزینه (`apps/api`).

---

## 📱 قابلیت‌ها و امکانات اپلیکیشن

### ۱. مدیریت و ثبت سفارش‌ها (Orders Management & Creation)
- **فهرست سفارش‌ها با فیلتر هوشمند**: تفکیک بر اساس وضعیت‌های «در حال پردازش»، «ارسال شده»، «در انتظار پرداخت»، «تحویل داده شده» و «لغو شده».
- **جستجوی سریع**: جستجو بر اساس شماره سفارش (`MOR-...`)، نام خریدار یا شماره موبایل.
- **جزئیات کامل سفارش**: مشاهده نام و مشخصات خریدار، نشانی پستی دقیق، کد پستی، اقلام خریداری‌شده با قیمت واحد و جمع جزء به تومان.
- **تغییر وضعیت سفارش**: امکان تغییر وضعیت (مثلاً انتقال به «ارسال شده» همراه با ثبت کد رهگیری پستی/تیپاکس).
- **ارتباط سریع با مشتری**: دکمه‌های مستقیم تماس تلفنی (`Call`) و ارسال پیامک (`SMS`) به خریدار با یک لمس.
- **ثبت سفارش جدید (سفارش تلفنی / حضوری / دستی)**:
  - انتخاب سریع مشتری از بانک اطلاعات یا تعریف خریدار جدید.
  - افزودن محصولات از کاتالوگ با کنترل تعداد و قیمت‌گذاری خودکار.
  - تعیین شیوه ارسال (پیشتاز، تیپاکس، پیک شهری، تحویل حضوری).
  - محاسبه آنی مبالغ کالاها، هزینه ارسال، تخفیف و مبلغ نهایی پرداختی به تومان.

### ۲. مدیریت و تعریف محصولات (Products & Catalog)
- **مشاهده کاتالوگ محصولات**: نمایش تصویر، عنوان فارسی، دسته‌بندی، قیمت فروش به تومان، کد انبارداری (SKU) و موجودی انبار.
- **هشدار کسری موجودی**: برچسب هشدار خودکار برای کالاهایی با موجودی ۵ عدد یا کمتر.
- **تعریف محصول جدید**:
  - ثبت عنوان فارسی، اسلاگ انگلیسی، دسته‌بندی و کد SKU.
  - ثبت قیمت فروش نهایی، قیمت قبل از تخفیف و قیمت تمام‌شده به تومان.
  - ثبت موجودی اولیه انبار و وزن کالا.
  - توضیحات کوتاه، توضیحات کامل و درج تصویر.
  - **جدول مشخصات فنی پویا**: امکان افزودن نامحدود ویژگی‌ها (مانند «نوع فرآوری»، «خلوص»، «نوع بسته‌بندی»).
- **ویرایش و انبارداری**: تغییر سریع موجودی انبار فیزیکی و تغییر وضعیت انتشار (منتشر شده / غیرفعال / بایگانی).

### ۳. بانک اطلاعات و سوابق مشتریان (Customer Directory & CRM)
- **لیست مشتریان**: نمایش نام، شماره تماس، استان/شهر، تعداد کل سفارش‌ها و جمع خریدهای انجام‌شده به تومان.
- **سطح‌بندی مشتریان**: برچسب‌های مشتریان طلایی، نقره‌ای و برنزی بر اساس حجم خرید.
- **پرونده و سوابق خرید**: نمایش مشخصات، نشانی‌های ثبت‌شده و تاریخچه کامل سفارشات هر مشتری با امکان ورود به جزئیات سفارش.
- **تماس و پیامک مستقیم**: برقراری تماس تلفنی یا ارسال پیامک هماهنگی مستقیم از درون پرونده مشتری.

### ۴. داشبورد و آمار لحظه‌ای (Dashboard Overview)
- آمار کل فروش به تومان و تعداد سفارش‌ها.
- تعداد سفارش‌های جدید در انتظار اقدام.
- شمارش کالاهای با کسری انبار.
- میانبرهای ثبت سریع سفارش و تعریف محصول.

### ۵. تنظیمات اتصال و کارکرد آفلاین (Server Config & Offline Support)
- قابلیت تنظیم داینامیک آدرس سرور (`Base URL`) جهت کار در شبیه‌ساز اندروید (`10.0.2.2:8080`)، شبکه محلی وای‌فای (`192.168.x.x:8080`)، یا سرور پروداکشن.
- دکمه تست آنلاین بودن سرور.
- پشتیبانی کامل از حالت آفلاین/دمو جهت تست روان حتی بدون اتصال به بک‌اند.

## 🚀 راهنمای اجرا روی گوشی اندروید

### ۱. اجرای سریع از طریق Expo Go:
1. مطمئن شوید در پوشه `apps/mobile` هستید.
2. دستور زیر را برای نصب وابستگی‌ها اجرا کنید:
   ```bash
   cd apps/mobile
   npm install
   ```
3. سرور توسعه را اجرا کنید:
   ```bash
   npx expo start
   ```
4. اپلیکیشن **Expo Go** را از گوگل پلی یا مایکت روی گوشی اندروید خود نصب کنید.
5. بارکد QR نمایش‌داده‌شده در ترمینال را با دوربین گوشی یا اپلیکیشن Expo Go اسکن کنید. برنامه بلافاصله روی گوشی شما اجرا می‌شود.

## 📦 راهنمای ساخت فایل نصب مستقیم APK برای اندروید

برای ساخت فایل `.apk` قابل نصب روی هر گوشی اندروید بدون نیاز به ابزار جانبی:

### روش اول: با استفاده از EAS Build (رایگان ابری)
1. ابزار EAS را نصب کنید:
   ```bash
   npm install -g eas-cli
   ```
2. وارد حساب کاربری خود شوید:
   ```bash
   eas login
   ```
3. دستور ساخت APK را اجرا کنید:
   ```bash
   cd apps/mobile
   eas build -p android --profile preview
   ```
4. پس از چند دقیقه، لینک دانلود مستقیم فایل `.apk` به شما داده می‌شود که می‌توانید آن را روی هر گوشی اندروید نصب کنید.

### روش دوم: خروجی به صورت وب اپلیکیشن (PWA / Web Preview)
برای تست سریع در مرورگر گوشی یا کامپیوتر:
```bash
cd apps/mobile
npx expo start --web
```

## ⚙️ ساختار پوشه‌های پروژه موبایل

```text
apps/mobile/
├── package.json          # پکیج‌ها و اسکریپت‌های پروژه
├── app.json              # تنظیمات اندروید، نام، پکیج و آیکون
├── eas.json              # تنظیمات ساخت فایل نصبی APK
├── tsconfig.json         # تنظیمات TypeScript
├── assets/               # تصاویر آیکون و اسپلش
└── src/
    ├── types/            # تایپ‌های داده (Order, Product, Customer, Stats)
    ├── theme/            # تم رنگی سبزینه، فاصله‌ها و سایه‌ها
    ├── utils/            # فرمت تومان، تقویم شمسی و اعداد فارسی
    ├── api/              # کلاینت REST API و کش آفلاین
    ├── context/          # مدیریت سراسری استیت و اتصال سرور
    ├── components/       # کامپوننت‌های Header, Button, Input, Card, Modal, Badge, TabBar
    └── screens/          # صفحات داشبورد، سفارشات، محصولات، مشتریان و تنظیمات
```
